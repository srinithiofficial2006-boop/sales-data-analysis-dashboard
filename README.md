 📊 Sales Data Analysis Dashboard

An interactive sales analytics dashboard built using Python, Pandas, Plotly, and Streamlit to explore sales performance, profitability, and regional business trends.

 📌 Project Overview

The Sales Data Analysis Dashboard transforms raw sales data into meaningful business insights through data cleaning, analysis, and interactive visualizations. It helps users explore sales trends, compare product categories, identify top-performing products, and understand regional performance.

🎯 Project Objectives

- Analyze sales and profit performance.
- Understand monthly sales trends.
- Compare product categories and regions.
- Identify top-performing products.
- Evaluate business profitability.
- Present insights through interactive charts and dashboards.

✨ Key Features

- **Sales Performance Analysis** – View important sales metrics.
- **Monthly Trend Analysis** – Explore monthly sales and profit trends.
- **Category Analysis** – Compare product categories.
- **Regional Analysis** – Analyze sales performance by region and state.
- **Product Analysis** – Identify top-performing products.
- **Profitability Analysis** – Examine profit and profit margins.
- **Interactive Visualizations** – Explore data through charts.
- **Data Exploration** – View sales records and filtered results.

⚙️ Installation and Setup

### 1. Clone the repository

git clone https://github.com/srinithiofficial2006-boop/sales-data-analysis-dashboard.git


### 2. Navigate to the project directory

cd sales-data-analysis-dashboard


### 3. Install dependencies


pip install -r requirements.txt


### 4. Run the dashboard


python -m streamlit run dashboard/app.py


The dashboard will open in your web browser.
